  <files>app/routes/division/players.tsx</files>
  <action>
Modify `app/routes/division/players.tsx` to manage compare selection via URL search params.

**Selection state management (in PlayersPage component):**
1. Read `compare` search param (comma-separated player IDs, e.g., `?compare=player-001`).
2. Parse into `selectedIds: string[]` array.
3. `handleCompareToggle(playerId: string)` function:
   - If playerId already in selectedIds: remove it (deselect)
   - If selectedIds.length === 0: add playerId (first selection)
   - If selectedIds.length === 1 and playerId not in selectedIds: add playerId, then navigate to `/division/compare?players=${selectedIds[0]},${playerId}` preserving existing weight params (`&w=...` if present)
   - If selectedIds.length >= 2: replace with just this playerId (start new selection)
4. Pass `selectedIds` and `onCompareToggle` as new props to `PlayerList`.

**Floating selection bar:**
- Render a fixed-position bar at the bottom of the viewport when `selectedIds.length === 1`:
  - Content: "1 jogador selecionado — selecione outro para comparar"
  - Include a "Limpar" (Clear) button that removes the `compare` param
  - Styling: `fixed bottom-4 left-1/2 -translate-x-1/2 bg-fm-accent text-white px-6 py-3 rounded-lg shadow-lg z-50 text-sm font-medium`
- When `selectedIds.length === 0`: no bar visible.
- When `selectedIds.length === 2`: bar not needed (navigation happens immediately).

**Do NOT:** Use React state for selection — must be URL params for shareability and persistence across navigation. Do not navigate on first selection — only navigate when second player is selected.
  </action>
