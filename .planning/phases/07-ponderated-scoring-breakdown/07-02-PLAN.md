```typescript
interface ScoreBreakdownProps {
  simpleAvg: number | null;
  ponderatedAvg: number | null;
  attributes: Record<string, number | null>;
  boostedAttrs: string[];
}
```

Behavior:
- Uses `useState(false)` for open/closed state (Pattern 4 from RESEARCH.md)
- Collapsed state: single button row showing "Média Simples: X.XX → Ponderada: Y.YY" with rotating chevron icon (`ChevronDown` from lucide-react, rotates 180° when open via `transition-transform duration-200 ${isOpen ? "rotate-180" : ""}`)
- Expanded state: per-attribute delta table with columns:
  - Attribute name (from `ATTRIBUTE_LABELS`)
  - Simple avg value (or "—" if null)
  - Ponderated contribution value (or "—" if null)
  - Delta (ponderated contribution − simple contribution, with +/− sign, or "—" if null)

Delta computation logic (inside component or as a helper):
- For each of the 12 ATTRIBUTE_KEYS:
  - Get `value = attributes[key]`
  - If null: render "Não observado" with "—" in all numeric columns
  - If non-null:
    - Simple contribution = `value / countOfNonNullAttributes` (this is how much this attribute contributed to the simple average)
    - Weight = `boostedAttrs.includes(key) ? 3 : 1`
    - Ponderated contribution = `(value * weight) / sumOfWeightedNonNullAttributes`
    - Delta = ponderatedContribution - simpleContribution
- Format all numbers to 2 decimal places

Styling:
- Outer: `border border-gray-200 dark:border-fm-border rounded-lg`
- Button: `w-full flex items-center justify-between px-4 py-3 text-sm font-medium`
- Table: `w-full text-xs` with header row (`text-gray-500 dark:text-fm-text-muted`) and data rows alternating or with subtle borders
- Delta column: green text for positive delta, red for negative (or use `text-fm-accent` for positive, `text-red-500` for negative)
