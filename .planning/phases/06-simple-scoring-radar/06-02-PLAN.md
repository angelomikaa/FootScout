# 06-02: Radar Chart & Profile Score Section

## Objective

Install Recharts, build a radar chart component showing the 12 per-attribute averages with a global headline number, and integrate it into the player profile above the scout reports section.

## Context

- Recharts `RadarChart` with `Radar`, `PolarAngleAxis`, `PolarGrid`, `PolarRadiusAxis`
- 12 axes with attribute labels, filled polygon in app accent color
- Global headline number displayed next to or above the radar
- Profile layout order: IdentityCard → PlayerScores → ScoutReports
- design: clean, filled polygon, no extra flourishes
