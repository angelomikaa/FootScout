# 06-01: Player-Level Score Aggregation

## Objective

Add a function that computes per-attribute averages across all submitted reports for a player, plus a global headline average. The existing `calculateOverallAverage()` works per-report — this is the player-level equivalent.

## Context

- Scoring schema: 12 attributes in 3 categories (pace, strength, stamina, agility, finishing, passing, dribbling, firstTouch, positioning, awareness, decisionMaking, workRate)
- Nulls excluded from denominator (never treat as 3)
- Only `status = 'submitted'` reports count
- Existing code path: profile loader fetches reports → ScorePlaceholder renders — the data pipeline already passes `reports` to the template

## Files

### `app/lib/scoring/player-average.ts` (NEW)

<read_first>
- `app/lib/scoring/average.ts` — existing per-report function, follow the same pattern
- `app/data/types.ts` — attribute types
</read_first>

<action>
Create `app/lib/scoring/player-average.ts` exporting:

```typescript
export interface PlayerAverages {
  attributes: Record<string, number | null>;  // 12 keys, null if no data
  globalAverage: number | null;                // null if no reports
  reportCount: number;
}
```

- `calculatePlayerAverages(reports: Report[]): PlayerAverages`
- Iterate submitted reports, for each of the 12 attribute keys collect non-null values
- Per-attribute avg = sum / count (null if no data at all)
- globalAverage = mean of all 12 per-attribute avgs (null if none have data)
- Exclude matchNotes attributes (attitude, coachability, intensity, impact, notes) — only physical, technical, tactical per D-12
</action>

<acceptance_criteria>
- `player-average.ts` exports `calculatePlayerAverages` and `PlayerAverages` type
- With 0 reports → all attributes null, globalAverage null, reportCount 0
- With 1 report of all-3s → each attribute = 3, globalAverage = 3, reportCount = 1
- With 2 reports where one attribute has null in one report → denominator adjusts
- Only physical/technical/tactical attributes processed (12 total)
</acceptance_criteria>
