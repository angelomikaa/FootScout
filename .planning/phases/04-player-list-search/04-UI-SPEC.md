## Phase 4 UI Elements

### Player List View
- Table layout with 6 columns: Player, Position, Club, Age, Reports, Last Scouted
- Search bar at top with position/club filters below
- Click row to navigate to player profile (Phase 5)
- Empty state when no players match filters

### Sort Functionality
- Click header to toggle: ascending → descending → no sort
- Visual indicator: ↑ (asc), ↓ (desc), none
- Default sort: Last scouted (newest first)
- Sort state in URL params for bookmarkability

### Filter Functionality
- Position dropdown: All, GK, DEF, MID, FWD (from player.position)
- Club dropdown: All clubs (dynamic from data)
- Search: Player name substring match (case-insensitive)
- Filters combine with AND logic
- Filter state in URL params for bookmarkability
