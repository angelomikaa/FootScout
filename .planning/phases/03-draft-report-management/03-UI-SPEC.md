## Phase 3 UI Elements

### Draft List View
- Card-based layout showing scout's saved drafts
- Each card shows: player name, match date, opponent, competition, last saved timestamp
- Actions: Resume, Delete (with confirmation)
- Empty state with CTA to start new report

### Draft Persistence
- Auto-save indicator ("Saving..." → "Saved")
- Manual "Save Draft" button on each form step
- Draft state preserved across navigation

### My Reports View
- List of submitted reports (from Phase 2)
- Filter by: All / Drafts / Submitted
- Sort by: Date (newest first)
