## Phase 5 UI Elements

### Profile Layout (Vertical Sections)
- Identity card at top: player info in a compact card with avatar area
- Scout Reports section: title + report card list below
- Player Scores section: placeholder container with dashed border, ready for Phase 6
- Sections separated by `border-t` and vertical gap (`space-y-8`)

### Identity Card
- Left: player name (xl, bold), position badge, club
- Right grid: DOB + age, nationality (flag emoji + code), preferred foot, height, weight
- Flat card with subtle shadow, rounded corners
- "← Back to players" link at top of page (above identity card)

### Report Card
- Header row: match date (bold) + opponent
- Subheader: competition + scout name in muted text
- Body: four category sections (Physical, Technical, Tactical, Match Notes)
- Each category: label + 2x2 grid of attribute scores
- Each attribute: name + value (or "—" for null)
- Scores shown as colored pills (blue bg for values, gray dash for null)
- Match Notes category includes free-text notes field below attribute grid
- Cards grouped with vertical gap (`space-y-4`), newest first

### Score Placeholder Section
- Dashed border card: `border-dashed border-gray-300 dark:border-gray-600`
- Title: "Player Scores" (lg heading)
- Body: "Scoring and radar charts coming in Phase 6" centered text
- Reserved space: min-height area that Phase 6 radar chart will occupy

### Empty State
- When player has no reports: identity card visible + centered empty state
- "No reports yet for this player" heading
- "Scouts can submit reports via the Scout Area." body text
- Link to `/scout/report` to encourage report creation

### 404 State
- Centered message: "Player not found" heading
- Descriptive body text
- "← Back to player list" link to `/division/players`

### Navigation Updates (in PlayerList)
- Player name text wrapped in `<Link to=\`/division/players/${id}\`>`
- Link styled with default color (not blue until hover — uses `text-gray-900 hover:text-blue-600`)
- Reports column: actual count from `getReportsByPlayer()` instead of hardcoded 0
- Last Scouted column: most recent report date instead of `createdAt`

### Identity Card Fields (display order)
1. Player Name (24px, bold)
2. Position Group + Specific Position (badges side by side)
3. Club
4. Nationality (flag emoji + ISO code)
5. Date of Birth + Age (e.g., "2011-05-12 (15 years old)")
6. Preferred Foot (Left / Right / Both)
7. Height (cm) + Weight (kg)
