# Roadmap: FootScout

## Overview

FootScout's roadmap flows from data foundation to data entry to data consumption. The scoring engine — the core differentiator — is built in two deliberate steps: simple average + radar first (so profiles are immediately visual), then ponderated weights + breakdown (so the differentiator ships with transparency baked in). Comparison comes last because it depends on both radar charts and weight configuration being ready.
