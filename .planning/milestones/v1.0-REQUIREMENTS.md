# Milestone v1.0: Requirements Archive

**Status:** ✅ SHIPPED 2026-05-15
**Milestone:** v1.0 MVP

## v1 Requirements — Final Status

### Data Model

- [x] **DATA-01**: Player entity with identity fields (name, date of birth, position, club, nationality) — ✅ Validated v1.0
- [x] **DATA-02**: Scout report entity linked to player with match context (date, opponent, competition, scout name) — ✅ Validated v1.0
- [x] **DATA-03**: Report contains 4 attribute categories: physical, technical, tactical, match notes — ✅ Validated v1.0
- [x] **DATA-04**: Each attribute rated on 1-5 scale with optional "not observed" (null) to prevent lazy 3s — ✅ Validated v1.0
- [x] **DATA-05**: Match notes captured as free-text field per report — ✅ Validated v1.0

### Scout Entry

- [x] **SCOUT-01**: Scout can create a new player entry when submitting first report — ✅ Validated v1.0
- [x] **SCOUT-02**: Scout can submit a report with staged form (physical → technical → tactical → notes) — ✅ Validated v1.0
- [x] **SCOUT-03**: Scout can save report as draft and resume later — ✅ Validated v1.0 (cookie set on submit/draft save)
- [x] **SCOUT-04**: Scout can view list of their own submitted reports — ✅ Validated v1.0

### Player Browsing

- [x] **BROWSE-01**: Division can view sortable, filterable player list — ✅ Validated v1.0
- [x] **BROWSE-02**: Division can search players by name, position, and club — ✅ Validated v1.0
- [x] **BROWSE-03**: Division can click from player list into detailed player profile — ✅ Validated v1.0
- [x] **BROWSE-04**: Player profile displays identity info, all reports, and visual scores — ✅ Validated v1.0

### Scoring & Visualization

- [x] **SCORE-01**: System calculates simple average per attribute across all scout reports for a player — ✅ Validated v1.0
- [x] **SCORE-02**: Player profile displays radar chart of attribute scores — ✅ Validated v1.0
- [x] **SCORE-03**: Division can select a preferential skill/attribute to activate ponderated scoring — ✅ Validated v1.0
- [x] **SCORE-04**: Ponderated average re-weights the selected attribute higher, showing how the overall score shifts — ✅ Validated v1.0
- [x] **SCORE-05**: Score breakdown shows simple average, ponderated average, and per-attribute delta explaining why the ponderated score differs — ✅ Validated v1.0

### Comparison

- [x] **COMP-01**: Division can select two players for side-by-side comparison — ✅ Validated v1.0
- [x] **COMP-02**: Comparison overlays radar charts of both players — ✅ Validated v1.0
- [x] **COMP-03**: Comparison respects active weight configuration (ponderated scores apply to both players) — ✅ Validated v1.0
